# StuSim-Baseline

> 复现 MIT 论文 [**Learning to Make Mistakes**](https://arxiv.org/abs/2412.06406) 的 MISTAKE-CYCLE+CORRECT 方法，基于 EEDI 数学教育数据集。

---

## 实验结果



| 指标 | 基座模型 | SFT 后 | 变化 |
|------|---------|--------|------|
| 整体预测准确率 | 24.69% | **34.77%** | ↑ +10.08% |
| 学生正确子集准确率 | 22.95% | **52.87%** | ↑ +29.92% |
| 学生错误子集准确率 | 26.45% | 16.53% | ↓ -9.92% |
| 循环一致性通过率 | 25.50% | 19.50% | — |
